# Relay contract — fixed before implementation

app.main:app; FastAPI factory create_app(db_path=None, source_dir=None, auto_start=None, clock=None, batch_size=5000). Epoch processing times **seconds UTC**; raw taxi timestamps are timezone-naive publisher wall time and stay strings. Environment RELAY_DB(data/relay.sqlite), RELAY_SOURCE_DIR(data/raw), RELAY_AUTO_START(0/1 default1), RELAY_SCAN_SECONDS(default300/bounds5..86400), RELAY_RETRY_SECONDS(default5/bounds1..300). One worker thread and process, file lock beside DB, lifespan-owned. app/security.py `protect(app)` supplies Host/origin/body/CSP protection. Mount existing app/static at/static and/index.

Known source filenames only green_2024-01.parquet,taxi_zone_lookup.csv,manifest.json. Source registration verifies raw hashes/sizes and schema/lookup; caps each file10MiB, rows100000. Runtime never downloads or executes source content. First enabled scan can enqueue actual source; subsequent unchanged scans dedup. Acquisition is separate script.

GET/health actual DB/worker liveness; HTTP503 if a configured worker is unexpectedly stopped.
GET/api/state returns {now,worker:{enabled,alive,busy,last_error},schedule:{enabled,interval_seconds,last_scan,next_scan,unchanged_scans},sources:[{id,name,sha256,bytes,rows,url,retrieved_at}],runs:[run newest30],published:{run_id,source_sha,lookup_sha,accepted,rejected,warning_rows,net_cents,output_rows,published_at}|null,alerts:[{id,run_id,message,created_at,acknowledged,simulated}],versions:{pipeline,rules}}.
Run={retry_cycle,id,state,trigger,simulated,fault_mode,source_sha,lookup_sha,partition,created_at,started_at,finished_at,attempts,max_attempts,cursor,total_rows,accepted,rejected,warning_rows,next_retry,error,published}. Preserve meaningful nulls.
GET/api/runs/{id} -> {run,attempts:[{cycle,number,started_at,finished_at,state,error,resume_cursor}],events:[{at,kind,message,cursor}],quality:[{code,severity,count}],examples:[{row_index,codes,severity,observed:{pickup,dropoff,pu_zone,do_zone,distance,total_amount,passengers}}]} (examples max50, errors prioritized from durable quarantine; quarantined is total retained count).
GET/api/runs/{id}/lineage -> {nodes:[{id,label,kind,sha256?,rows?,state}],edges:[{from,to,operation,fields?}],run_id}. Actual source hashes→validation/quality→aggregate; pending outputs explicit.
GET/api/daily?run_id=<optional> -> [{day,borough,trips,net_cents,warning_rows}], published normal run if omitted; an explicitly requested completed experiment can be inspected. Failed/incomplete run must not expose partially published metrics.
POST/api/scan {} -> {run_id,created,reason}; exact current source unchanged returns created:false and originalrunid. This registers/queues, no synchronous full processing. Optional source unavailable recorded clearly.
POST/api/experiments {fault_mode:"once_after_checkpoint"|"always_after_checkpoint"} -> run, always creates an explicitly simulated-fault experiment over the same real immutable source in isolated run staging. Fail at first committed chunk after cursor>0. Once mode fails once then retries/resumes, always mode exhausts3attempts. It must not contaminate observed data or existing successful output.
POST/api/runs/{id}/retry {} -> run; only failed/retry_wait, preserve run/attempt/event history, new bounded retry cycle (record cycle and do not pretend earlier attempts disappeared). Retry validates input source checksums still match.
POST/api/schedule {enabled:bool,interval_seconds:int5..86400} -> schedule. Persist configuration, coalesce missed scans; the UI uses interval5 for verification only.
POST/api/alerts/{id}/ack {} -> acknowledgment. No outbound alerts.

Quality policy/identity/publish/checkpoint semantics exactly PLAN. Use per-operation SQLite connections and BEGIN IMMEDIATE claims, a process file lock (Mac/Linux fcntl) and in-process queue mutex so two callers cannot process same run. Tests injected clock and explicit engine.process_once()/tick() rather than sleeps; expose engine via app.state.engine for independent testing. Background engine must catch/report recoverable failures and not silently die. A restart with exclusive lock recovers interrupted running jobs into queued/retry_wait preserving committed cursor/staging. Tests don't start background unless lifecycle case, never network.

UI clients rely on these stable response shapes; contract changes must keep the client and API consistent. Source, Docker, browser and held-out fault checks provide independent acceptance evidence.
